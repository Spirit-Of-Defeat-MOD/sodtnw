Generated with the built-in image generation tool on 2026-10-24. Project assets: `skeleton_pixel.png` and `trick_pumpkin.png` in this directory. Runtime code animates the skeleton's arms, task title and speech bubble; candy sprites use the shared collision animation.

## Skeleton prompt

Use case: game animation sprite. A single small charming mischievous Halloween skeleton, front view, waist-up skull, neck, rib cage, spine and little pelvis, two clearly visible round shoulder joints. No arms or hands: they will be animated separately in code. Symmetric upright pose, grin with a few clear blocky teeth, large dark eye sockets with tiny warm amber eye glints, rounded skull. Chunky crisp pixel-art style matching cute small pixel duck/cat/penguin sprites, strong dark charcoal/maroon pixel outline, warm ivory bone, restrained grey shadow, readable at 64 pixels tall. Full silhouette centered with generous transparent margins. True transparent background. No ground, no border, no box, no glow, no text, no clothes, no props. Cute spooky, not realistic, avoid gore or detailed illustration.
