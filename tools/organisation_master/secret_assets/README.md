# Theme effect artwork

Generated with the built-in image-generation tool. The PNGs preserve transparent backgrounds. The duck is an eight-frame, four-column/two-row atlas; other movement and the sunset gradient are animated in the application. Existing RR branding and the Stallonian portrait remain in their theme folders.
