# Andorran Dream

Dark black-and-gold theme centered on Russian Imperial visual motifs: double-headed eagles, imperial crowns, laurel engraving, black enamel and antique gilding. Working surfaces remain nearly black, with deep antique-gold headers, warm ivory text and muted gold labels. Gold buttons use dark text; bottle-green selections use pale gold text for contrast.

## Resources

- `theme.json`: stable ID `andorran-dream`, complete palette and font settings.
- `assets/button.png`: restrained vertical gold gradient.
- `assets/imperial_eagle.png`: standalone transparent, Russian Imperial inspired double-headed-eagle crest.
- `../../icons/task_icons_andorran_dream.png` and matching JSON: 80 generic task symbols.
- `../../icons/alt_history/alt_history_andorran_dream.png` and matching JSON: 80 alternate-history symbols.
- Both icon catalogs' registry files include this theme ID.

The two sheets retain the original stable icon IDs and subject ordering. Their individual manifests specify actual image dimensions and pixel crop boxes. Preserve transparency and proportions when displaying icons. Decoration stays on the assets; editors and task lists use quiet, solid surfaces. Task age retains green/yellow/red meaning.

Only theme resources and icon registry data were added. No application source or executable was changed or rebuilt.
