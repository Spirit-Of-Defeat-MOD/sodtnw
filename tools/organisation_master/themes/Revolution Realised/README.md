# Revolution Realised

Theme resources for Organisation Master.

- `theme.json`: palette, fonts, asset paths, original sources and dimensions.
- `assets/`: actual RR textures converted losslessly to RGBA PNG for Tkinter/Pillow.

These are theme items, not a mockup. The app has not been modified or rebuilt. A theme loader must consume this definition before the theme can be selected. Preserve the borders when resizing panels and buttons; source control textures may contain multiple frames.
