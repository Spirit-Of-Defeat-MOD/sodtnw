# Rising Sun

Japanese cherry-blossom theme with warm ivory working surfaces, sakura-pink headers, ink-indigo text and restrained vermilion accents. A light palette with dark readable text, soft blush buttons and lacquer-inspired icon finishes.

## Files

- `theme.json`: theme ID `rising-sun`, existing color/font schema and button asset.
- `assets/button.png`: subtle vertical ivory-to-blush gradient; labels use the existing `parchment_foreground` key.
- `../../icons/task_icons_rising_sun.png` and matching JSON: 80 generic symbols.
- `../../icons/alt_history/alt_history_rising_sun.png` and matching JSON: 80 alternate-history symbols.
- The icon catalogs' registry files include this theme ID.

Both sheets preserve their existing icon IDs and ordering. Each manifest includes the actual sheet dimensions and pixel crop coordinates. Maintain alpha and aspect ratio when displaying icons. Decoration stays on the symbols, leaving task lists and notes uncluttered. Green/yellow/red age indicators retain their meaning against ivory surfaces.

Only theme resources and icon registry data were added. No application source or executable was changed or rebuilt.
