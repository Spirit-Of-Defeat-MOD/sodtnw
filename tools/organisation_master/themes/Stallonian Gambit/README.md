# Stallonian Gambit

Affectionate meme theme based on the supplied friend's portrait: fluffy brown fringe, over-ear headphones, moustache, short beard and cream shearling collar. Petrol-teal panels and warm copper/cream details echo the portrait. The joke is a mock-serious gamer strategist, with portrait cameos worked into otherwise recognizable task symbols.

## Resources

- `theme.json`: stable ID `stallonian-gambit`, complete palette and fonts.
- `assets/button.png`: cream-copper gradient button.
- `assets/stallonian_badge.png`: transparent cartoon portrait badge with chess-knight details.
- `../../icons/task_icons_stallonian_gambit.png` and matching JSON: the original 80 generic task subjects with portrait details.
- `../../icons/alt_history/alt_history_stallonian_gambit.png` and matching JSON: 80 alternate-history task subjects with portrait details.
- Both icon catalogs' registry files include this theme ID.

The icon subjects and stable IDs follow the original sets, so task assignments remain compatible. Each manifest provides actual sheet dimensions and crop boxes. Preserve alpha and fit proportionally. The tiny face details are decorative; task labels remain the primary way to identify tasks at small sizes.

The original photograph is not copied into this package; only generated illustrated derivatives are included. Image generation used the supplied portrait as the likeness reference. This theme contains no political imagery.

Only theme resources and icon registry data were added. No application source or executable was changed or rebuilt.
